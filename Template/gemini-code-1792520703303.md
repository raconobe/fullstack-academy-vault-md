## 📖 Chapter Breakdown & Key Highlights

### Chapter 01: Introduction to Dynamic Web Content
* **Status:** ✅ Completed
* **Core Concept:** **Request/Response Cycle**
* **Key Takeaways:**
  * Web browsers act as clients making HTTP requests (GET/POST) to a web server running PHP.
  * PHP scripts generate dynamic HTML output before sending it back to the client.

---

### Chapter 02: HyperText Markup Language (HTML)
* **Status:** ✅ Completed
* **Core Concept:** **Semantic Markup & Structure**
* **Key Takeaways:**
  * Semantic HTML tags (`<nav>`, `<article>`, `<form>`) improve accessibility and document hierarchy.
  * Form inputs require unique `name` attributes to pass parameters into backend server scripts.

---

### Chapter 03: Cascading Style Sheets (CSS)
* **Status:** ✅ Completed
* **Core Concept:** **Styling & Layout Foundations**
* **Key Takeaways:**
  * Understanding the CSS Box Model (`margin`, `border`, `padding`, `content`) is vital for precise positioning.
  * Use external stylesheets to separate presentation from business logic and markup structure.

---

### Chapter 04: Installing PHP and SQL
* **Status:** ✅ Completed
* **Core Concept:** **Local Development Environment Setup**
* **Key Takeaways:**
  * Local LAMP/XAMPP environments manage local HTTP servers (Apache), PHP runtime environments, and MySQL database engines.
  * Configuration files (`php.ini`, `my.cnf`) govern execution timeouts, error reporting levels, and file upload limits.
