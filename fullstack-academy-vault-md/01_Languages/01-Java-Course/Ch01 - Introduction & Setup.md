==**You can build a multi-page markdown website using a static site generator like**== **[VitePress](https://vitepress.dev/) or [MkDocs](https://www.mkdocs.org/) and host the output on either [GitHub Pages](https://docs.github.com/en/pages) or [Firebase Hosting](https://firebase.google.com/docs/hosting).**

Because neither GitHub Pages nor Firebase can directly parse complex multi-page markdown folder structures out of the box without a build step, you need a lightweight tool to convert your `.md` files into a clean HTML website first.

---

Step 1: Choose a Multi-Page Generator

- **VitePress:** Fast, modern, and uses a `config.js` file to automatically generate a sidebar navigation menu from your `.md` files.
- **MkDocs (with [Material Theme](https://squidfunk.github.io/mkdocs-material/)):** Classic, highly organized, and designed specifically for multi-page documentation sites using a simple `mkdocs.yml` file.

---

Step 2: Organize Your Markdown Files

Create a local project folder on your computer with a structure like this:

- `docs/` (or `src/`) folder containing your `.md` files (e.g., `index.md`, `guide.md`, `about.md`).
- A configuration file (`config.ts` for VitePress or `mkdocs.yml` for MkDocs) where you list your pages to build the website navigation menu.
- Run the local preview command (e.g., `npx vitepress dev`) to test your pages locally.

---

Step 3: Deploy to Your Chosen Host

Option A: Hosting on GitHub Pages

1. Build your static site files locally (usually outputs to a folder like `dist` or `site`).
2. Push your project to a GitHub repository.
3. Use a [GitHub Actions workflow](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-github-pages) to automatically build and deploy your site whenever you push changes to your markdown files. Many generators like VitePress offer a one-click GitHub Actions setup guide.

Option B: Hosting on Firebase Hosting

1. Install the [Firebase CLI](https://firebase.google.com/docs/cli) in your terminal by running `npm install -g firebase-tools`.
2. Log in with `firebase login` and initialize your project folder using `firebase init hosting`.
3. Set your public directory to your generator's output folder (e.g., `dist` or `site`).
4. Run your generator's build command, then deploy live instantly by running `firebase deploy`.
