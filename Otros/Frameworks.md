# Scalate: Scala Template Engine
https://scalate.github.io/scalate/index.html

Scalate is a [Scala 2.10, 2.11 and 2.12](http://www.scala-lang.org/) based [template engine](http://en.wikipedia.org/wiki/Template_engine_\(web\)) for generating text and markup which can be used in the following [frameworks](https://scalate.github.io/scalate/documentation/frameworks.html) and environments:

Jade is the daddy of HTML template engines for Scala

[Jade](http://jade-lang.com/) is a [neater](https://scalate.github.io/scalate/documentation/jade-syntax.html) dialect of [Haml](http://haml-lang.com/) / [Scaml](https://scalate.github.io/scalate/documentation/scaml-reference.html) which is a very DRY template language for creating HTML markup.
[Jade](http://jade-lang.com/) is a [neater](https://scalate.github.io/scalate/documentation/jade-syntax.html) dialect of [Haml](http://haml-lang.com/) / [Scaml](https://scalate.github.io/scalate/documentation/scaml-reference.html) which is a very DRY template language for creating HTML markup.


Scalate supports the following template formats

- [Mustache](https://scalate.github.io/scalate/documentation/mustache.html) which is a Scala dialect of [Mustache](http://mustache.github.io/) for logic-less templates which also work inside the browser using [mustache.js](http://github.com/janl/mustache.js)
- [Scaml](https://scalate.github.io/scalate/documentation/scaml-reference.html) which is a Scala dialect of [Haml](http://haml.info/) and is very DRY for generating HTML / XHTML
- [Jade](https://scalate.github.io/scalate/documentation/jade.html) which is an even more DRY dialect of [Scaml](https://scalate.github.io/scalate/documentation/scaml-reference.html) for HTML / XHTML markup generation
- [SSP](https://scalate.github.io/scalate/documentation/ssp-reference.html) which is like [Velocity](https://scalate.github.io/scalate/documentation/ssp-reference.html#velocity_style_directives), JSP or Erb from Rails
