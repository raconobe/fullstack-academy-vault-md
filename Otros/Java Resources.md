### **Option A: Stanford Algorithms Specialization (4 Courses)**

*Best if you prefer pseudo-code, mathematical analysis (Big-O proofs), and language flexibility.*

#### **Course 1: Divide and Conquer, Sorting and Searching, and Randomized Algorithms**

* **Key Topics:** Asymptotic notation ($O, \Omega, \Theta$), Master Method for recurrence relations, MergeSort, QuickSort (randomized pivot selection), Karatsuba integer multiplication, and Karger's randomized min-cut algorithm.
* **Core Data Structures:** Arrays, Recursion trees.
* **Primary Output:** Algorithm runtime analysis and implementations of divide-and-conquer paradigms.

#### **Course 2: Graph Search, Shortest Paths, and Data Structures**

* **Key Topics:** Breadth-First Search (BFS), Depth-First Search (DFS), Topological Sort, Strongly Connected Components (Kosaraju's algorithm), Dijkstra's shortest path, 2-Sum problem variants.
* **Core Data Structures:** Heaps/Priority Queues, Balanced Binary Search Trees (AVL, Red-Black), Hash Tables, and Bloom Filters.
* **Primary Output:** Graph traversal engines and dynamic lookup structures.

#### **Course 3: Greedy Algorithms, Minimum Spanning Trees, and Dynamic Programming**

* **Key Topics:** Optimal caching/scheduling, Prim’s and Kruskal’s Minimum Spanning Tree (MST) algorithms, Huffman coding, Knapsack problem, Sequence alignment, and Optimal Binary Search Trees.
* **Core Data Structures:** Disjoint-set (Union-Find), Dynamic Programming lookup tables.
* **Primary Output:** Optimization solutions using greedy choices and memoization/dynamic tables.

#### **Course 4: Shortest Paths Revisited, NP-Complete Problems and What To Do About Them**

* **Key Topics:** All-pairs shortest paths (Bellman-Ford, Floyd-Warshall, Johnson’s algorithm), NP-completeness reductions (3-SAT, Traveling Salesperson), local search heuristics, and approximation algorithms.
* **Core Data Structures:** Distance matrices, graph adjacency matrices.
* **Primary Output:** Heuristic solvers for computationally intractable problems.

### **Option B: Princeton Algorithms (2 Parts)**

*Best if you prefer production-level code implementations, memory management, and concrete Java data structures.*

#### **Part I: Elementary Data Structures, Sorting, and Searching**

* **Module 1: Union-Find & Analysis of Algorithms**
* Dynamic connectivity, Quick-Find, Quick-Union, Weighted Union with path compression, Big-O analysis, memory profiling.


* **Module 2: Stacks, Queues, Bags & Elementary Sorts**
* Resizing arrays, linked-list implementations, Selection Sort, Insertion Sort, Shellsort, shuffling algorithms.

* **Module 5: Balanced Search Trees & Geometric Applications**
* 2-3 Trees, Left-leaning Red-Black BSTs, 1D/2D range search, $k$-d trees, line segment intersection.


* **Module 6: Hash Tables & Applications**
* Separate chaining, linear probing, hash functions, set implementations, dictionary applications.



#### **Part II: Graphs, Strings, and Advanced Topics**

* **Module 1: Undirected & Directed Graphs**

### **Why You See This Message**

Kiron offers two different levels of access on its platform:

  

- **Unverified / Basic Account:** Anyone can create a free Kiron account and access a small selection of basic, open-access courses.
    
      
    
- **Verified Learner Account:** Grants full access to premium programs—including corporate/university partnerships like **Coursera for Refugees**, advanced language courses, and certified tracks.
    
      
    

### **How a User Becomes a "Verified Learner"**

To unlock these courses, Kiron requires users to upload official legal documentation confirming their status as a **refugee, asylum seeker, internally displaced person (IDP), or member of an eligible underserved group**.

  

1. **Document Submission:** The user submits proof (e.g., asylum application, refugee ID card, or protection status documents).
    
      
    
2. **Review Rounds:** Kiron holds verification rounds (typically 4 times a year) to process and approve submitted documents.
    
      
    
3. **Approval:** Once Kiron verifies the paperwork, the account is upgraded to "Verified/Approved," removing the lock on those premium courses.
    
      
    

If you do not have refugee or international protection status to submit, those specific courses will remain locked, and you won't be able to bypass the verification prompt.
