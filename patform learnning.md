

Para pasar directamente a la práctica con un enfoque **"learning by doing"** (crear proyectos reales desde cero en lugar de solo leer documentación o seguir tutoriales pasivos), las siguientes plataformas y recursos son las mejores opciones actualmente:

  

### 1. Plataformas de Aprendizaje Basadas en Proyectos (Hands-On)

- **Execute Program**
    
      
    - **Enfoque:** Micro-ejercicios interactivos en el navegador con repetición espaciada.
        
          
        
    - **Ideal para:** Fijar sintaxis y conceptos avanzados en JavaScript, TypeScript, SQL y Python escribiendo código real en cada pantalla.
        
          
        
- **Boot.dev**
    
      
    - **Enfoque:** Gamificado y totalmente práctico (Backend, Python, Go, Algoritmos, SQL).
        
          
        
    - **Ideal para:** Desarrollar proyectos complejos desde la terminal local y el navegador con validación de tests automáticos.
        
          
        
- **Frontend Mentor**
    
      
    - **Enfoque:** Desafíos de desarrollo web del mundo real a partir de diseños profesionales en Figma.
        
          
        
    - **Ideal para:** Maquetación HTML/CSS, JavaScript Vanilla y frameworks (React, Vue, Astro) creando proyectos listos para tu portafolio.
        
          
        
- **Codewars / LeetCode**
    
      
    - **Enfoque:** Resolución de problemas algorítmicos y lógica pura de programación.
        
          
        
    - **Ideal para:** Pulir la velocidad de implementación, estructuras de datos y refactorización.
        
          
        

### 2. Repositorios de Proyectos "Build Your Own X"

Si prefieres construir herramientas reales desde cero siguiendo guías paso a paso sin depender de plataformas cerradas:

  

- **Build Your Own X (en GitHub)**
    
      
    - Guias paso a paso para construir desde cero tu propio servidor web, motor de base de datos, compilador, clon de Git o shell de comandos.
        
          
        
- **Coding Challenges (por John Crickett)**
    
      
    - Desafíos semanales donde te entregan una especificación técnica (ej. "Construye un clon de `wc`", "Construye tu propio balanceador de carga") y tú escribes todo el código en el lenguaje que prefieras.
        

### 3. Rutas de Proyectos Graduales para Práctica Directa

|**Nivel**|**Proyecto Recomendado**|**Conceptos a Poner en Práctica**|
|---|---|---|
|**Intermedio**|**CLI Tool en C / Python**|Parsing de argumentos, I/O de archivos, manipulación de memoria/strings.|
|**Full Stack**|**CRUD PHP / Laravel + SQLite**|Autenticación basada en sesiones, migraciones, ORM, protección CSRF/XSS.|
|**Avanzado**|**Motor de Reglas / Parser**|Estructuras de datos (árboles/grafos), evaluación de expresiones, lógica condicional.|

### 1. Plataformas de Aprendizaje Basadas en Proyectos

- **[Execute Program](https://www.executeprogram.com/)**
    
      
    
    Micro-ejercicios interactivos en el navegador con repetición espaciada. Ideal para dominar sintaxis y conceptos clave de TypeScript, SQL, JavaScript y Python escribiendo código en cada lección.
    
      
    
- **[Boot.dev](https://www.boot.dev/)**
    
      
    
    Plataforma gamificada enfocada en desarrollo Backend (Python, Go, SQL, Estructuras de Datos). Escribes y validas código directamente contra tests automáticos.
    
      
    
- **[Frontend Mentor](https://www.frontendmentor.io/)**
    
      
    
    Proporciona diseños profesionales (archivos Figma) e impresos de requerimientos para construir proyectos web reales (HTML/CSS, JS Vanilla, React, Astro) y sumarlos a tu portafolio.
    
      
    
- **[Codewars](https://www.codewars.com/)**
    
      
    
    Retos de código ("katas") orientados a lógica pura, optimización de algoritmos y refactorización continua.
    
      
    

### 2. Repositorios y Guías "Build Your Own X"

- **[Build Your Own X (en GitHub)](https://github.com/codecrafters-io/build-your-own-x)**
    
      
    
    Un repositorio con guías paso a paso para construir desde cero un servidor web, un motor de base de datos, un intérprete/compilador, un clon de Git o una shell de terminal.
    
      
    
- **[Coding Challenges (por John Crickett)](https://codingchallenges.fyi/)**
    
      
    
    Desafíos semanales con especificaciones técnicas reales (ej. crear un clon de `wc`, un balanceador de carga o un cliente HTTP) para implementar en el lenguaje que prefieras.
